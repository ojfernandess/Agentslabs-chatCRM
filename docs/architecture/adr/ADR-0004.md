# ADR-0004: Prompt IR Schema v1.0

| Campo | Valor |
|-------|-------|
| **Data** | 2026-07-30 |
| **Autor** | OpenNexo Platform — Arquitetura Principal |
| **Versão** | 1.0.0 |
| **Componente** | Prompt Compiler / Prompt IR |
| **Status** | accepted |
| **Categorias** | Architecture, Prompt Compiler, Runtime |

## Motivo

O runtime re-interpretava markdown do playbook em múltiplos parsers a cada turno. Fase 1 do ROADMAP exige representação intermédia única antes da execução.

## Decisão

Introduzir **Prompt IR v1.0** em `apps/api/src/lib/agent-engine/contract/`:

- `PromptIR` — schema versionado
- `compilePromptToIR()` — compilação única (static extract + turn resolution)
- `promptIrToContract()` — adapter para `PromptContract` legacy
- `PromptIRCache` — cache de extracção estática por `playbookHash`
- `IntentAnalyzer` — intenção separada da selecção de tools
- `TurnContext.promptIr` — IR disponível em todo turno

## Arquitectura

```
Playbook markdown
  → extractStaticPromptIR (cached)
  → resolveTurnPolicy + resolveRequiredTools
  → PromptIR
  → promptIrToContract → PromptContract (compat)
```

Parsers legacy (`requiredToolNamesParser`, `turnPolicyParser`) permanecem como **extractors** internos — não duplicam lógica no runtime de produção.

## Patches endereçados

P-050, P-051, P-052, P-053, P-054, P-092

## Rollback

`compilePromptContract` continua API pública; remover `promptIr` de `TurnContext` e reverter `PromptCompiler.ts` se necessário.
