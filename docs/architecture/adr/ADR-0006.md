## Motivo

Fase 2 unificou o Execution Spine; plan/contract ainda duplicavam `resolveTurnPolicy` e `buildExecutionTurnPlan` fora do Prompt IR. Fase 3 consolida num único planner.

## Decisão

Introduzir **UnifiedExecutionPlanner**:

```
Prompt IR (1× compilePromptToIR)
  → executionTurnPlanFromPromptIr (sem 2ª resolveTurnPolicy)
  → Facts + CapabilityGraph
  → PolicyEngine v2 (PolicyRule[] do IR)
  → PlanGraphBuilder (DAG steps/tools)
  → UnifiedExecutionPlan
```

**Componentes:**
- `planner/UnifiedExecutionPlanner.ts` — merge TurnPlan + EIL
- `planner/PlanGraphBuilder.ts` — ordenação por deps
- `eil/PolicyEngine.evaluatePromptIrPolicyRules()` — IR policies
- `ExecutionEngine.replan()` — replan baseado em Facts

**Duplicação eliminada:**
- `buildTurnContext` usa IR + unified planner (não `buildExecutionTurnPlan` + `resolveEilTurn` separados)
- `ExecutionPlanner.buildExecutionIntelligencePlan` delega ao unified planner
