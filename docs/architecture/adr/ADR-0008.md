# ADR-0008: Structural Validation Only

| Campo | Valor |
|-------|-------|
| **Data** | 2026-07-30 |
| **Autor** | OpenNexo Platform — Arquitetura Principal |
| **Versão** | 1.0.0 |
| **Componente** | Supervisor / Workflow Validator |
| **Status** | accepted |
| **Categorias** | Architecture, Supervisor |

## Motivo

Supervisor e WorkflowValidator interpretavam playbook via regex NLP e `resolveTurnPolicy` em runtime. Fase 5 despromptiza: validação só com Contract, Plan, Facts, Policies.

## Decisão

**Supervisor v2** — input estrutural:
- `ExecutionContract` (required/pending/forbidden tools, facts)
- `ExecutionIntelligencePlan` (EIL)
- `detectReplyActions` para conclusão/operacional (centralizado)
- `ViolationRouter` → camada upstream (planner/scheduler/policy/llm)

**WorkflowValidator v2:**
- Sem `resolveTurnPolicy(behaviorConfig)` — `turnPolicy` vem do IR/contrato
- `promptAssemblyAudit` → severidade **info** (observabilidade, não gate)
- `routedViolations` no report para MCP/RCA

**Supervisor DEIXA de:** interpretar markdown, fallback replies, regex hotel disperso.

**Supervisor PASSA a:** tools do plano, facts, policies, completion criteria.

## Patches endereçados

P-060, P-061, P-062, B-005 (parcial — wire MCP em deploy)

## Critérios de saída

- [x] ViolationRouter + structuralValidation
- [x] Supervisor routedViolations no trace
- [x] WorkflowValidator sem resolveTurnPolicy
- [x] promptAssemblyAudit observability-only
- [ ] MCP: supervisor checks em execuções staging
