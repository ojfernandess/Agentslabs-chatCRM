## Motivo

Fase 5 despromptizou validação; o LLM ainda recebia playbook completo e escolhia tools livremente. Fase 6 reduz papel do LLM a raciocínio + NL + args.

## Decisão

**Context packer** (`TurnContextPacker`) — step objective + facts summary + tools do passo.

**Filtered tool catalog** — `filterToolsForCurrentStep` a partir de pending/exclusive/flow step.

**LLM sandbox** — `evaluateLlmToolSandbox` bloqueia tools fora do plano.

**ReplyTemplateRenderer** — templates declarativos `{{facts.*}}`; corpos em `REPLY_TEMPLATE_BODIES`, não Modelo S1/S9 hardcoded no synthesizer.

**ReplySynthesizer** — delega renderização ao renderer; aceita `promptIr` opcional.

## Contrato LLM

```
RECEBE:  step objective, facts summary, allowed tools, user message
PRODUZ:  natural language, tool args, disambiguation
NÃO FAZ: tool selection livre, workflow, fallback de template
```
