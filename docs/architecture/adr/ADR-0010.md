## Motivo

Fases 1–6 desacoplaram planner, scheduler, supervisor e LLM sandbox, mas domínio hotel (Embratur, URL check-in, guards) permanecia espalhado em `agentNativeLlm.ts`, `ReplyTemplateRenderer` e `automationHttpToolExecute`. Fase 7 move metadados para Prompt IR e parsers HTTP para adapters.

## Decisão

**Playbook enrichment** (`compiler/playbookEnrichment.ts`) — `behaviorConfig.playbookEnrichment` injecta `checkinLink`, template overrides e facts default no IR sem alterar playbooks legacy.

**Tool outcome adapters** (`checkin/toolOutcomeAdapters.ts`) — facade HTTP-only: `adaptHttpCheckInPayload`, `checkInPreInvokeBlockReason` via CapabilityGraph + fallback legacy.

**LlmRuntimeBridge** — wire monolito: `appendPackedLlmContext`, `gateLlmToolCall` quando `unifiedSpineMode !== off`.

**compilePromptToIR** — chama `enrichPromptIr` no final do pipeline.

**REPLY_TEMPLATE_BODIES** — URL hardcoded → `{{facts.checkinLink}}`.
