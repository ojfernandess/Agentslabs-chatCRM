## Motivo

O Motor Padrão (`openconduit`) executava via monolito `agentNativeLlm.ts`, contornando `ExecutionEngine`. Fase 2 do ROADMAP exige spine unificado com rollout gradual e observabilidade MCP.

## Decisão

Introduzir **UnifiedSpineBridge** com modos configuráveis:


| Modo      | Comportamento                                                          |
| --------- | ---------------------------------------------------------------------- |
| `off`     | Legacy — monolito governa plan/contract (default)                      |
| `shadow`  | ExecutionEngine em paralelo; legacy entrega; divergências logadas      |
| `primary` | TurnContext do engine; fallback legacy se divergência **crítica** (2b) |
| `only`    | Spine exclusivo excepto LLM adapter (2c)                               |


**Configuração:**

- `behaviorConfig.agentEngine.unifiedSpineMode`
- Env override: `AGENT_ENGINE_UNIFIED_SPINE=shadow|primary|only|off`

**Integração (2c — only):**

- `requiresLegacyTurnContextBuilder()` — `only` não invoca `buildTurnContext`
- `resolveEngineTurnContext()` — API explícita sem legacy
- `LlmTurnAdapter.invokeLlmTextGeneration()` — LLM isolado do plan/contract
- `recordPhase('execute_llm')` antes da geração
- LangGraph trace: spine via executor nativo



## Arquitectura

```
agentNativeLlm (Motor Padrão)
  ├── UnifiedSpineSession.begin → ExecutionEngine.beginTurn
  ├── refresh (schedule / validate / recover)
  ├── resolveTurnContext (only: engine only; primary: engine+fallback; shadow: legacy+compare)
  ├── recordPhase(execute_llm) → LlmTurnAdapter
  ├── finalize → engine timeline
  └── tools / reply synthesis (até Fase 6/7)
```
